## Brand & Style

This design system establishes a high-stakes, mission-critical autonomous agent control center disguised within an airy, calming pastel aesthetic. By hybridizing the rigorous operational telemetry, swarm monitoring, and human-in-the-loop approval workflows of deep-tech engineering with the effortless optimism, perforated ticket cards, and soothing tinted surfaces of modern travel booking apps, it radically reduces cognitive fatigue during incident management.

The brand persona is serene, authoritative, and tactfully delightful:
- **Atmospheric Calm:** Subdued tints of mint cyan, soft lavender, and sky blue replace oppressive dark-mode terminals, neutralizing the stress of multi-agent swarm anomalies.
- **Ticketed Command Metaphor:** Approvals, swarm dispatches, and agent execution plans are framed as perforated transit vouchers or flight passes, turning system commands into tactile physical boarding events.
- **High-Contrast Grounding:** Deep obsidian/onyx anchors (`#0F172A`) establish resolute typographic authority and immediate primary call-to-action recognition amid airy backdrops.
- **Precision Typography:** Crisp, open-geometry geometric sans-serif type matched with technical monospace metrics delivers instantaneous legibility for high-velocity telemetry triage.

## Colors

The color system reconciles high-pressure system operations with an inviting, light-filled pastel sanctuary. Deep onyx and carbon hues ground critical decisions, while functional tints communicate telemetry health without visual strain.

### Palette Architecture
- **Primary Anchor (`#0F172A`)**: Deep carbon slate applied to primary action buttons, active navigation toggles, prominent headlines, and core data readouts.
- **Secondary / Swarm Pulse (`#006A61`)**: Teal pine deployed for autonomous agent operational heartbeats, validated telemetry nodes, and steady-state indicators.
- **Tertiary / Swarm Intelligence (`#7C3AED`)**: Electric violet reserved for autonomous agent synthesis, model routing, and approval vouchers.
- **Neutral Canvas & Surfaces**:
  - Base Canvas: `#F8FAFF` to `#F1F5F9`.
  - Elevated Container Cards: `#FFFFFF`.
  - Soft Outlines & Dashed Perforations: `#E2E8F0` and `#CBD5E1`.
  - Secondary/Meta Typography: `#64748B`.

### Semantic & Swarm Telemetry Colors
- **Mint Telemetry (`#E8FAF6`)**: Tinted container for nominal background agent jobs; text and icons use `#0D9488`.
- **Lavender Intelligence (`#F0EFFF`)**: Human-in-the-loop pending approval ticket envelopes; text and icons use `#6D28D9`.
- **Sky Observer (`#E0F2FE`)**: Streaming network data and diagnostic traces; text and icons use `#0284C7`.
- **Approval Emerald (`#059669` / `#ECFDF5`)**: One-tap human approval confirmation for swarm changes.
- **Anomaly Crimson (`#DC2626` / `#FEF2F2`)**: Breached guardrails, kill-switches, and urgent human rejections.

## Typography

Typography relies on **Plus Jakarta Sans** for comprehensive brand cohesion across headers, controls, and narrative telemetry feeds, delivering geometric clarity with generous apertures. For code execution payloads and swarm CLI commands, **JetBrains Mono** provides unyielding tabular discipline.

- **System & Mission Headers:** Display and headline levels leverage tight negative tracking (`-0.02em`) to produce a poised, high-end editorial posture.
- **Node & Agent Signifiers (`code-badge`):** Station-like 3-to-4 letter agent cluster codes (e.g., `SWRM`, `GATE`, `EXEC`, `NODE`) mirror airport IATA typography with extra-bold weights and expanded tracking.
- **Telemetry Readouts & Logs:** Real-time counters, throughput numbers, and token latencies must employ `font-variant-numeric: tabular-nums` to eliminate jitter during continuous polling.
- **Metadata Badges:** Subtitles and priority indicators use `label-xs` in uppercase tracking (`letterSpacing: 0.04em`) to establish authoritative classification across compact pill chips.

## Layout & Spacing

The layout is built for mission control triage on mobile, tablet, and responsive desktop dashboards.

- **Mobile Viewport (360px – 440px):** Single-column command stream. Outer margins are locked to `margin: 1.25rem` (20px) to prevent finger cramp around display hardware bevels.
- **Adaptive Grid Structure:** On wide screens (768px+), a 12-column responsive fluid grid deploys with `gutter: 1rem`. Agent telemetry metrics, approval cards, and agent health cards snap to 4, 6, or 12 column spans.
- **Horizontal Swarm Strips:** Metric telemetry dials (GPU/VRAM load, agent activity rates, queue depth) scroll horizontally edge-to-edge, offsetting the start position with `margin: 1.25rem` and providing a trailing peek to signal infinite queue telemetry.
- **Stacking Spacing Rhythm:** Component interiors utilize `space-md` (14px) and `space-lg` (20px) padding. Consecutive operational cards are separated by `space-md`, while major operational sections (Telemetry vs. Human-In-The-Loop Queues) are demarcated by `space-xl` (28px).

## Elevation & Depth

Visual hierarchy uses soft tonal stratification and ambient light dispersion rather than dense, harsh drop shadows. Surfaces feel weightless, pristine, and float gently above one another.

- **Level 0 (Atmospheric Canvas):** `#F8FAFF` flat canvas base, washed with subtle top-to-bottom pastel gradients (`#F0EFFF` to `#E8FAF6`) at 20% opacity. Zero shadow.
- **Level 1 (Telemetry Tiles & Resting Cards):** Crisp pure `#FFFFFF` resting upon the canvas, encased with a delicate `1px solid rgba(226, 232, 240, 0.8)` boundary and an ambient shadow: `0px 6px 20px -4px rgba(15, 23, 42, 0.04), 0px 2px 6px -1px rgba(15, 23, 42, 0.02)`.
- **Level 2 (Active Approval Tickets & Modals):** Elevated actionable items awaiting human review. Features a soft lavender ambient perimeter: `0px 14px 32px -6px rgba(124, 58, 237, 0.12), 0px 4px 10px -2px rgba(15, 23, 42, 0.04)`.
- **Level 3 (Floating Mission Dock & Bottom Actions):** Floating control bar suspended above viewport bounds with a 16px bottom offset. Utilizes high-grade frosted glass (`backdrop-filter: blur(16px)`, `background: rgba(255, 255, 255, 0.88)`), encased with `1px solid rgba(255, 255, 255, 0.9)`, and cast by `0px 12px 36px -4px rgba(15, 23, 42, 0.08)`.

## Shapes

The design system embraces a hyper-rounded, tactile shape language (Pill-shaped, Level 3). Curvature is exaggerated to humanize autonomous machine intelligence and impart a relaxed, non-combative posture.

- **Primary Command Surfaces & Enclosures:** Large cards, ticket containers, and agent cluster summaries feature continuous rounded corners of `24px` to `28px` (`rounded-3xl`).
- **Interactive Controls & Toggles:** Fully pill-shaped (`rounded-full` / `9999px`) across action buttons, category switches, input prompt bars, and telemetry badges.
- **Sub-Containers & Terminal Drawers:** Inner nested payload viewers and code inspection frames adopt `14px` to `16px` corner radii, ensuring balanced concentric curvature with host cards.
- **Perforated Ticket Notches:** Approval cards and execution commands feature physical boarding pass cutouts: inward semicircular punch-holes (`radius: 10px`) carved along lateral seams, bridged by a delicate dashed line.

## Components

### 1. Buttons & Command Triggers
- **Primary Execution CTA:** Fully pill-shaped (`height: 52px`), deep onyx background (`#0F172A`), white label (`#FFFFFF`), `label-lg` weight. Active press triggers tactile scale-down (`transform: scale(0.98)`).
- **Binary Human-in-the-Loop Pair:**
  - *Approve Action:* Pill-shaped, background `#059669`, text `#FFFFFF`, accompanied by a trailing checkmark icon.
  - *Reject / Abort:* Pill-shaped, crisp white background, `1.5px solid #FCA5A5`, text `#DC2626`.

### 2. Perforated Approval Ticket Cards
- Specialized dual-segment cards with circular cutouts at lateral dividing lines.
- **Header Segment (Voucher Top):** Pastel lavender (`#F0EFFF`) or mint (`#E8FAF6`) background. Displays swarm agent ID (`code-badge`), execution timestamp, and risk confidence score.
- **Perforated Seam:** Inward notch cutouts connected by a horizontal dashed line (`#CBD5E1`).
- **Body Segment (Voucher Bottom):** White card base showcasing the proposed tool call, affected infrastructure nodes, a collapsible dark monospace drawer (`#131B2E`) for raw script previews, and dual Approve/Reject action buttons.

### 3. Swarm Route & Pipeline Connectors
- Inspired by flight transit timelines. Horizontal dashed track (`#CBD5E1`) connecting agent stages (e.g., `PLANNER` ➔ `CODER` ➔ `AUDITOR`).
- Intermediate nodes are depicted by 8px glowing circular nodes (`#0D9488` for healthy, `#DC2626` for blocked), with a micro agent icon traversing the path.

### 4. Status Chips & Pill Badges
- **Swarm Active:** Soft mint background (`#E8FAF6`), text `#0D9488`, featuring an animated 6px breathing green status beacon.
- **Awaiting Approval:** Soft lavender background (`#F0EFFF`), text `#6D28D9`, clock icon.
- **Guardrail Tripped:** Soft peach/red background (`#FEF2F2`), text `#DC2626`, shield alert icon.

### 5. Input Fields & Quick Prompt Bar
- Floating capsule container (`height: 56px`, `rounded-full`) anchored at the screen base. Surface `#FFFFFF` with `1px solid #E2E8F0`, interior left icon for agent persona selection, dynamic input text (`Plus Jakarta Sans`), and an onyx circular send button (`42px x 42px`) on the trailing edge.
- Positioned directly above the input bar is a scrollable horizontal tray of pastel pill suggestion chips (e.g., `Deploy Swarm Alpha`, `Scale Workers +4`, `Dry Run Rollback`).

### 6. Floating Navigation Dock
- Symmetrical pill floating 16px above the canvas bottom. Contains 4 to 5 key destinations (Overview, Agents, Approvals, Traces, Settings).
- Active item indicated by solid onyx pill or glowing electric violet node dot; inactive items rendered in `#64748B`.
